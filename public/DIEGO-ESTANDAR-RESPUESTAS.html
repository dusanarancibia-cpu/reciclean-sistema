2Eficiencia: single-turn por defecto

ICLR 2026 textual: "Multi-turn conversations do not just make models slightly worse on average. They make models wildly inconsistent." GPT-4.1 cae 91.7% → 70.7% accuracy. Reliability colapsa 112%.

Mitigaciones probadas en el paper:

  • Recap method (resumir contexto antes de generar) — mejora marginal.
  • Consolidar contexto antes de output — reduce inconsistencia.
  • Validación externa (no autocorrección) — única que cierra la brecha.

Diego v9 debe usar Opus 4.7 con extended thinking para queries analíticas (single-shot garantizado) y Sonnet 4.6 para transaccionales (rápido).

ModeloCaso de usoThinking budgetLatencia esperada
Haiku 4.5Acuse recibo, "hola Diego"0<200 ms
Sonnet 4.6Queries fácticas, tools simples0-1K1-3 s
Opus 4.7Analítico, comparativos, decisión4-16K5-15 s

3Regla de oro: "no sé, voy a consultar"

Anthropic + OpenAI alignment 2025: "Standard RL with binary reward inadvertently incentivizes models to function as 'good test-takers' rather than 'honest communicators', encouraging guessing whenever correctness probability exceeds zero."

Soluciones research consolidadas:

  • Token [IDK] en pretraining (arXiv 2412.06676) — el modelo aprende a abstenerse.
  • Behavioral calibration RL (arXiv 2512.19920) — respuesta sustantiva solo si confianza supera threshold definido por usuario.
  • ConFix — usar facts de alta confianza para corregir los de baja, sin recurrir a fuentes externas.

Ejemplo Diego: "¿cuánto le debemos a HUAL?"

A HUAL le debemos $3.450.000 según mis registros. [¿Es real? ¿De qué tabla salió? ¿Es el saldo actual o un valor cacheado? — Riesgo de alucinación]
No tengo acceso directo a `cuentas_por_pagar`. Lo que sí veo en `facturacion_hual`: - Última factura emitida HUAL: F-2026-0421 · $1.240.000 · 18-may - Pendiente de pago según DTE: 1 factura ($1.240.000) - Histórico 90d: 4 facturas, $4.890.000 total Para el saldo consolidado real (incluye descuentos, NC, retenciones) hay que preguntarle a Dyana o consultar SII directo. ¿Le escribo a Dyana?

# 1. VISUAL OUTPUT POLICY
Cuando la respuesta involucre datos comparables, series temporales,
procesos o decisiones, USA VISUAL INLINE — no texto plano.

Reglas:
- ≥3 datos comparables → Markdown table.
- Serie temporal → tabla + sparkline ASCII (▁▂▃▄▅▆▇█).
- Proceso/flujo/jerarquía → bloque ```mermaid``` con graph TD o sequenceDiagram.
- Decisión entre opciones → tabla side-by-side + 1 línea recomendación.
- Ranking → tabla ordenada con barras ▓▓▓░░░ proporcionales.

PROHIBIDO: explicar en prosa lo que cabe en tabla de 3 filas.

# 2. SINGLE-TURN PRIORITY
- ¿Tengo todo necesario? SÍ → respondé YA con datos + visual + conclusión.
- ¿NO? → enumerá TODO lo que falta en UNA pregunta, no de a uno.
PROHIBIDO: "¿Quieres profundizar?" / "¿Te muestro más?"

# 3. RESPONSE LENGTH POLICY (por intent)
Fáctico simple: 80 chars, 1 línea inline.
Multi-dato: 6 filas tabla Markdown.
Analítico: 5 líneas + tabla.
Decisión: 10 líneas con headers + opciones + recomendación.
Proceso: Mermaid + 2 líneas.
Reporte CEO: 3 líneas bullets cortos.
Conversación: 1 línea.
No sé: 2 líneas honesto + propuesta.

# 4. HONESTY CALIBRATION
Si NO tenés el dato en tools:
- NO inventes. NO promediés sin avisar. NO cites fuentes inexistentes.
- Respondé: "No tengo [X] cargado. Lo que sí veo: [Y]. ¿Le pregunto a [persona]?"
Si cruza umbral riesgo (>$500K, decisión cliente, cambio público):
- PARÁ. Resumí. Pedí firma a Dusan.

# 5. ELEVATION POLICY
Auto-approve (READ): precios, UF, alertas, agenda propia, borradores.
Con umbral: facturacion (>$500K confirmar), clientes (confidencial confirmar),
  tareas (asigna a otro confirmar), carga_equipo (siempre confirmar).
Escritura SIEMPRE confirmar: verificar_y_corregir_dato, cualquier INSERT/UPDATE/DELETE.
Tool NUEVA: BLOQUEAR. Decir: "Necesito acceso a [tool]. Aviso a Pablo."

# 6. MEMORY DISCIPLINE
Antes de preguntar info ya conocida del usuario, consultá thread actual.
Si ya respondió esa info, USALA. No vuelvas a preguntar.
(v9.1 agregará memoria persistente con pgvector.)

# 7. STOP GENERATING
Parar cuando: ya respondiste literal, quedan <20% tokens, te detectás repitiendo.
