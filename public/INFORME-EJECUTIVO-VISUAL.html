05Reglas de Coherencia entre PCs

Antes de declarar "PC X inactivo" cruzar 3 fuentes. Solo si las 3 muestran inactividad, reportar. Nunca decir "PC parado" si hay evidencia de actividad real.

Las 3 fuentes obligatorias

#FuenteQué dice
1panel.pc_heartbeatÚltimo latido del PC
2BITACORA-CIERRE.mdÚltima tarea cerrada
3GitHubCommits/PRs últimas 24h
🚫
NUNCA decir "PC X no trabaja" o "PC X está parado" si hay evidencia de actividad real. Si heartbeat está vencido pero hay commits → el heartbeat está desactualizado, no el PC. Anotar en BLOQUEOS.md, no bloquear trabajo.
