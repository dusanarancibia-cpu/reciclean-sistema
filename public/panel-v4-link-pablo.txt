PROCESO DE SWAP FINAL (cuando se apruebe)
═══════════════════════════════════════════════════════════════════

Cuando aprueben el v4, el swap a producción es:

  git switch main
  git pull origin main
  cp public/panel-rdo.html public/panel-rdo.html.pre-v4.bak
  git checkout origin/replit/plan-dusan -- public/panel-rdo-v4.html
  mv public/panel-rdo-v4.html public/panel-rdo.html
  git add public/panel-rdo.html public/panel-rdo.html.pre-v4.bak
  git commit -m "swap: panel-rdo v3 → v4"
  git push origin main   # via PR con review
